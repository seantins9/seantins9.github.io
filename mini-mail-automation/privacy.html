Privacy notice

This notice covers Gmail data handled by Mini Mail Automation, Sean’s private operational tool. Contact: shenghaowu97@gmail.com.

Data accessed and why

After owner authorization, the application uses Gmail read access to locate configured business alerts, inspect message and thread identifiers and headers, and extract limited diagnostic fields from approved alert bodies. Thread metadata may include other participants. It also reads its own sent reports to check recipients, subject, message identifier and report content against the prepared report.

Gmail send access is used for the existing daily Crisp report to the owner’s fixed address, with no CC or BCC. Crisp access is authorized separately. The application does not send automatic customer replies or call Gmail’s attachment-download endpoint.

Processing and sharing

Codex/OpenAI receives operational metadata and diagnostic context needed for the task. DeepSeek may receive task context only for a separately authorized task; it has not been used in the current critical workflow. Provider handling is governed by the applicable service terms and account settings; this notice makes no blanket promise about provider retention or training.

The application does not publish email contents or credentials on these pages. These static pages contain no scripts, analytics or third-party resources. GitHub Pages hosts them and handles ordinary web requests under its own policies.

Storage and retention

Credentials are kept in private files on owner-operated hosts. Operational records on owner-operated computers and a server can include message identifiers, hashes, audit state, report drafts and prepared outgoing messages. These records support deduplication, sent-report verification, recovery and diagnosis. Credentials are not stored in this public site or its repository.

There is no fixed automatic deletion schedule represented by this notice. The owner manages retained files and records through the relevant application, host and provider controls. Copies handled by external providers are subject to those providers’ controls and policies.

Stopping access and deleting records

The owner can disable the automation and revoke its access in the Google Account’s third-party connections settings. Revoking this application’s Google access prevents further Gmail API access under that authorization. It does not delete existing mail, operational records or provider-held records. Contact the owner above for questions about retained application records or their deletion.
